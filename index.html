        喷笔是怎么把漆喷出来的

        没按扳机：气在走，漆被针挡住出不来

        先分清三种供漆方式

        类型漆杯位置怎么供漆适合
        重力式笔身上方重力 + 喷嘴负压模型最常用，省漆、好洗、低气压也能喷
        虹吸式笔身下方全靠负压吸大量喷涂，需要较高气压
        侧壶式笔身侧面重力 + 可旋转少量、要转角度喷死角

        逐件拆开看

        ① 漆杯

        作用　储漆，靠重力把漆送到笔身底部。

        细节　常见 7 / 10 / 15 毫升。杯壁刻度只能参考，不同漆密度不一样。带盖的杯子能防止溶剂挥发，喷到一半停下来也不至于结皮。

        出问题　杯底残留旧漆 → 下次喷出颗粒；杯口没盖 → 漆面结皮，掉进漆里堵笔。

        ② 笔身漆道

        作用　把漆从杯底引到喷嘴，是一条很细的内部通道。

        细节　通道直径通常不到 1 毫米，转弯处最容易积漆。洗笔时稀释剂要能从杯口一路流到喷嘴口，才算洗干净。

        出问题　通道里有干漆 → 出漆断续、带渣、越喷越小。

        ③ 漆针

        作用　顶住喷嘴堵住漆路；后退多少，出漆就有多少。

        细节　一根前端带锥度的细钢针，直径通常 0.2–0.3 毫米。针尖必须和喷嘴孔完全同心，轻微弯一点就会偏喷。

        出问题　针尖弯 → 偏喷、滴漆；针身有干漆 → 拉动发涩、出漆忽大忽小；针尖磨损 → 关不死，一直滴。

        ④ 喷嘴

        作用　最细的那个孔，决定线宽和雾化质量。

        细节　0.2 / 0.3 / 0.5 毫米是常见规格。喷嘴、漆针、气帽是三件配套的一组，不能混着换——0.3 的针配 0.2 的喷嘴，针会顶不到底。

        出问题　堵 → 喷不出或偏喷；用针捅过 → 孔被扩，雾化永久变粗，只能换。

        ⑤ 气帽（喷嘴帽）

        作用　把压缩空气导向喷嘴口，形成一圈高速气流。

        细节　气帽中间的环形缝隙决定负压强度。有的气帽能旋动调节喷幅（扇形/圆形）。

        出问题　气帽小孔堵了 → 偏喷（一边有漆一边没有）、喷出来是斜的。这是「偏喷」最常见的原因，不是喷嘴坏。

        ⑥ 扳机

        作用　两段行程：下压打开气阀，后拉带动漆针。

        细节　双动笔这两段独立，可以先吹气再出漆；单动笔按下就同时出气和漆。松手时先关漆、后关气，能避免残漆滴在模型上。

        出问题　行程发涩 → 出漆忽大忽小；O 圈干涩 → 回弹慢、关不严。

        ⑦ 气阀

        作用　扳机下压时打开，压缩空气才进笔身。

        细节　弹簧 + 阀杆 + O 圈，在扳机正下方。软管的气从这里进，再沿笔身内部气道走到气帽。

        出问题　O 圈老化 → 漏气、气压不稳、一直出气；阀杆卡住 → 按下没反应。

        ⑧ 尾调

        作用　限制漆针后退的最大行程，用来定「最大出漆量」。

        细节　拧紧 = 针退得少 = 出漆小；拧松 = 出漆大。做细节时先拧到很小，靠扳机微调，不容易一次喷多。

        出问题　拧太紧 → 后拉没反应，会误以为堵了。

        原理：三步

        ① 负压吸漆

        压缩空气从气帽的环形缝隙高速冲出，喷嘴口气压下降形成负压。漆杯里的漆被大气压压着，就从漆道被吸到喷嘴口——这就是文丘里效应。漆杯越高、密封越好，吸得越稳。

        ② 气流撕碎成雾

        漆一碰到高速气流就被撕成细滴。液滴越细，漆面越平滑。影响它的三件事：气流速度（气压）、漆的黏度（稀释比例）、表面张力（稀释剂种类）。太稠撕不碎 → 粗点拉丝；太稀 → 流挂盖不住。

        ③ 出漆量和气压要匹配

        针退得越多，漆流越大。但气流能带走的漆有限：超过这个量就喷粗点甚至拉丝。所以调的时候两件事一起动——漆稠了加气压，漆稀了减出漆，只动一样永远调不好。

        部件 vs 故障

        症状先查哪里
        偏喷，一边有漆一边没有气帽小孔堵了（最常见），其次针尖弯
        出漆断续、越喷越小漆道有干漆，或者漆太稠
        停手后一直滴漆针尖没顶严、针尖磨损、喷嘴口有干漆
        按下扳机没反应气阀卡住 / 尾调拧太紧 / 喷嘴全堵
        雾化变粗、颗粒大气压不足、漆太稠、或者喷嘴被捅扩过孔
        一直漏气气阀 O 圈老化

        为什么双动笔要先气后漆

        先出气可以把表面灰尘吹走，也能先确认雾化正常；停手时先关漆再关气，喷嘴口不会积着一坨漆往下滴。 用熟了就是条件反射——按下 → 后拉 → 松漆 → 松气。

        气泵：从电机到喷嘴

        整条链是：电机转 → 曲轴把旋转变成往复 → 活塞压缩空气 → 单向阀 → 储气罐稳压 → 压力开关控制启停 → 调压阀定输出 → 水隔除水 → 喷笔。

        ⓪ 电机：动力来源

        作用　带动曲轴旋转，是所有动作的起点。

        细节　模型用气泵多为 1/5–1/3 马力。直驱（电机轴直接连曲轴）最常见，便宜但抖动大；皮带传动更静音。

        出问题　碳刷磨损 → 转速掉、打不上压；散热差 → 烫手、自动保护停机。

        ① 曲轴 + 连杆：旋转变往复

        作用　把电机的旋转变成活塞的上下往复。

        细节　曲轴偏心量决定活塞行程，行程 × 缸径决定排气量。

        出问题　连杆轴承旷 → 噪音变大、敲缸，排气量下降。

        ② 活塞 + 气缸：压缩

        作用　下行吸气，上行把空气压进管路。

        关键　往复式出气天生是脉动的，单靠它供气会一道一道。

        出问题　活塞环磨损 → 打不上压、一直转不停。

        ③ 单向阀：不让气倒流

        作用　只允许气往罐里走。

        细节　活塞回程时管内压力高，没有它会倒灌回气缸。

        出问题　阀片脏或老化 → 关机掉压快、频繁启动。

        ④ 储气罐：把脉动抹平

        作用　吸收活塞脉动，出气才平稳。

        细节　罐越大越稳，充气也越久。模型用 3–6 升够用。

        出问题　无罐直连 → 喷出来一顿一顿，还容易积水。

        ⑤ 压力开关：自动启停

        作用　罐压掉到下限启动，到上限停止。

        细节　一般 3–4 bar 启停，再由调压阀降到 1.5–2 bar 用。

        出问题　启停过于频繁 → 漏气或罐太小。

        ⑥ 调压阀：决定手上的气压

        作用　把罐内高压降到你要的输出并稳住。

        细节　罐压高、输出低才稳；表上读的是输出压力。

        出问题　坏了 → 气压忽高忽低，漆面一会粗一会流挂。

        ⑦ 水隔：把水挡在笔外

        作用　空气压缩后会析水，水隔靠离心加滤芯分离。

        细节　必须装在调压阀之后、软管之前。

        出问题　忘了放水 → 白点、鱼眼，还总在漆快干时出现。

        气泵有哪几种

        上面画的只是最常见的一种（无油活塞 + 储气罐）。市面上还有几类，原理不同，适合的场景也不一样。

        类型原理噪音出气适合
        无油活塞（直驱）电机直连曲轴，活塞往复大 70–85 dB有脉动，需罐入门、预算低、能忍受噪音
        有油活塞同上，但缸内有润滑油中 65–75 dB较平稳耐用、长时间工作
        静音活塞低转速 + 大缸径 + 隔音罩小 30–45 dB平稳家里用、晚上喷
        隔膜式橡胶膜片往复，无油小 40–55 dB流量小喷笔套装、小面积、偶尔用
        电磁式（电磁泵）线圈吸动衔铁，50 Hz 往复小 45–60 dB（嗡嗡声）脉动明显，必须配罐喷笔套装、小件、静音要求一般
        涡旋式两个螺旋盘相对运动压缩很小 35–45 dB连续平稳高端、长时间连续喷
        冰箱压缩机改装拆制冷压缩机 + 罐 + 过滤很小 35–45 dB平稳但流量小DIY、性价比高
        气罐 / CO₂预充压缩气体，无电机无恒定，但会衰减应急、外出、无电源

        电磁泵是怎么工作的

        没有电机、没有曲轴、没有碳刷。它靠市电本身的频率在往复——插上电就一直以每秒 50 次的节奏在动。

        ① 线圈：把电变成磁

        交流电过线圈产生交变磁场，磁场一吸一放，频率就是市电的 50 Hz。

        没有碳刷、没有换向器——这是它寿命长的根本原因。

        ② 衔铁 + 膜片：磁力变位移

        衔铁被吸动，推着膜片每秒鼓起、压下 50 次。

        行程很小（通常 1–2 毫米），所以流量不大，但结构极简。

        ③ 两个单向阀：往复变单向

        膜片鼓起时排气阀开、进气阀关；压下时反过来。

        一进一出，气流就成了单向。阀片脏了流量立刻掉。

        ④ 储气罐：必须配

        50 Hz 的脉动比活塞更密，没有罐会喷得一顿一顿。

        小罐（1–3 升）就够，主要是抹平高频抖动。

        一句话总结

        电磁泵 = 线圈 + 衔铁 + 膜片 + 两个单向阀。它用市电的频率工作，结构比活塞机简单得多， 但压力和流量都小。喷笔套装里那种小方盒子，基本就是这个。

        直驱 vs 皮带

        直驱　电机轴直接连曲轴。便宜、体积小，但抖动和噪音都大。

        皮带　电机通过皮带带曲轴。转速低、更静音、寿命长，但要定期检查皮带松紧。

        无油 vs 有油

        无油　不用换油，但活塞环磨损快、噪音大、寿命相对短。

        有油　耐用、噪音低，但要定期换油，且必须配油水分离，否则会把油雾喷进漆里。

        冰箱压缩机 DIY

        用旧冰箱压缩机 + 灭火器罐 + 油水分离，静音效果极好（35 dB 左右）。

        缺点是排气量小、需要一定的动手能力，焊接和密封做不好会漏气。

        气罐 / CO₂ 瓶

        没有电机，靠预充气体。完全静音，压力恒定，适合小件和外出。

        缺点是压力会随用量下降、需要充气或换罐，长期成本高。

        怎么选

        在家喷、怕吵　→ 静音活塞，或者冰箱压缩机 DIY。

        预算有限、偶尔喷　→ 无油活塞带罐，3–6 升。

        只喷小零件、上色为主　→ 隔膜式或气罐就够。

        长时间连续喷涂　→ 有油活塞或涡旋，注意占空比。

        参数怎么看模型够用的值

        为什么一定要带储气罐

        无罐气泵每往复一次气压就抖一次，喷笔对这种抖动极敏感——出漆量跟着抖，漆面就一道深一道浅。 储气罐相当于一个水库，把抖动吃掉。贵一百块也优先买带罐的。

        稀释：先学会判断稠稀，再记比例

        比例只是起点。同一支漆放久了会变稠，不同批次的浓度也不一样——真正要练的是看：漆挂在搅拌棒上流下来的样子。

        漆种稀释剂比例（漆 : 稀释剂）注意
        硝基漆郡士/田宫专用硝基稀释剂1 : 1.5～2最常用；别用香蕉水代替
        水性丙烯专用水性稀释剂或蒸馏水1 : 1～1.5别用自来水，矿物质会发花
        珐琅漆田宫 X-201 : 1～2干得慢，适合渗线和手涂
        补土（瓶装）同系稀释剂1 : 1～1.5稀一点才能喷，太稠会拉丝
        金属漆同系稀释剂1 : 2稀一些，颗粒才排得开
        透明漆同系稀释剂1 : 2薄喷，太稠会咬底
        稀释剂怎么选

        标准型　通用，干速适中，最稳。

        缓干型　夏天、潮湿天用，防白化和橘皮。干得慢，别急着叠层。

        快干型　低温或赶时间用，但更容易橘皮。

        金属专用　有的品牌有，能让颗粒排得更整齐。

        四个常见错误

        1. 用错稀释剂　硝基配珐琅会絮凝，直接堵笔。

        2. 一次倒太多稀释剂　稀了只能加漆，越调越多。

        3. 稀释后放一周　溶剂挥发，比例变了。

        4. 用眼睛估比例　买个带刻度的小杯，几块钱。

        手法：距离、重叠、速度

        项目数值为什么
        距离15–20 cm近了流挂，远了干喷起粉
        走枪速度每秒约 20–30 cm停住就流挂，太快盖不住
        重叠率1/3～1/2不漏喷，也不会一次太厚
        角度尽量垂直斜喷漆膜厚薄不均
        层间10–15 分钟摸着不粘手再上下一层
        薄喷 vs 湿喷

        薄喷　漆量小、干得快、盖不住底色。适合多层堆、过渡、细节。

        湿喷　一次喷到发亮，表面平整。适合最后一道、透明漆。

        规则　前面几层薄喷打底，最后一道湿喷收光。反过来必流挂。

        十字交叉

        第一层横着走枪，第二层竖着走枪。这样漏喷的地方会被第二层补上，比一个方向喷三遍都匀。

        大面积（车壳、翅膀）一定要用，小零件可以省。

        先边角后大面

        边角、凹槽先喷到，再整体走一遍大面。反过来大面喷完再补边角，接缝会明显。

        手别摸

        指腹有油脂，摸过的地方上不了漆，会出现缩孔（小坑）。要检查干没干，用纸胶带轻贴一下。

        环境：温度、湿度、灰尘

        湿度能喷什么建议
        40–60%什么都能喷最理想
        60–75%实色、补土透明和光泽要小心，加缓干剂
        75–85%只做实色透明/光泽会发白（blushing）
        >85%别喷开除湿机，或者等
        温度

        20–25℃ 最稳。

        低于 15℃　干得慢，容易流挂、发白；漆膜可能一直不硬。

        高于 30℃　溶剂挥发太快，起橘皮、干喷。

        通风与防护

        硝基漆有毒性，必须在通风处喷：开窗 + 抽风机 + 防毒口罩（不是普通医用口罩）。

        别在卧室、别在小孩在的房间。喷完继续通风半小时。

        降尘

        喷前在地上洒点水，或者用喷壶在空气里喷一层水雾，让灰尘落下去。

        漆面有颗粒，八成是灰尘，不是漆的问题。

        干燥

        自然干最好。要加速用远距离暖风，别贴着吹——表面干太快会起橘皮。

        硝基漆表干 10–15 分钟，实干 24 小时。没干透就叠层，必花。

        保养：每次五分钟，省下一支笔

        ① 倒残漆

        把杯里剩的漆倒回瓶里（过滤一下），别留在杯里过夜。

        ② 过稀释剂

        杯里倒稀释剂，晃一晃，喷掉。重复到喷出来是清的。

        ③ 拆针和喷嘴

        抽出漆针擦干净；喷嘴拆下来泡稀释剂几分钟，别用针捅。

        ④ 擦干装回

        所有件擦干再装，螺纹处别硬拧。下次用之前先试喷一下。

        周期做什么
        每次用完四步清洗（上面那四步）
        每周拆开喷嘴和针，彻底清一次漆道；检查 O 圈有没有发硬
        每月螺纹和扳机转轴上一滴专用润滑油；检查气阀漏不漏气
        长期不用彻底洗净晾干，针单独放，别长期顶着喷嘴
        三个禁忌

        别用针捅喷嘴　孔一扩，雾化永久变粗，只能换。

        别把整支笔泡在溶剂里　O 圈会老化发胀。

        别用机油润滑　会腐蚀胶圈，用专用润滑脂。

        什么时候该换件

        喷嘴　雾化明显变粗、清洗后仍偏喷。

        漆针　针尖弯了、关不严一直滴。

        O 圈　漏气、扳机回弹慢、接口渗漆。

        正常的漆面是怎么形成的

        下面八张卡讲的是"坏了长什么样"。但在那之前得先知道**正常**长什么样——不然连判断的基准都没有。

        ① 一层漆怎么变成膜

        刚喷上　是一层湿的漆雾液滴，表面坑坑洼洼。

        流平　溶剂挥发、表面张力把液滴拉平——这一步决定表面平不平。

        成膜　溶剂跑完，树脂连成一片。此时表面才定型。

        ② 为什么必须薄喷多层

        薄层　溶剂能从上往下跑掉，每层都能流平。

        厚层　表面先干结成皮，里面的溶剂出不来，被困住 → 起泡、发白、后期塌陷。

        所以「薄喷三层」不是玄学，是让每一层都有机会干透和流平。

        ③ 干燥的三个阶段

        表干　10–15 分钟，摸着不粘手。此时可以喷下一层。

        实干　约 24 小时，溶剂基本跑完。

        完全固化　几天到一周，硬度才上来。这时候抛光才不会留痕。

        ④ 什么样的漆面算「平」

        漆面微观上永远有起伏，关键是起伏的尺度。

        流平好 → 反光是一整片、能照出直线；流平差 → 反光散开，就是橘皮。

        侧光贴着看，是最快的判断方法。

        正常漆面的五个标志

        1. 颜色均匀　没有深浅不一的斑块，边缘也没有积漆。

        2. 反光连续　侧光看，反光是一条完整的光带，不是碎的。

        3. 没有凸起　手指轻扫，感觉不到颗粒和硬点。

        4. 边缘干净　遮盖线笔直，没有锯齿状渗色。

        5. 厚度一致　棱角处没有明显变厚（那里最容易流挂）。

        先判断：漆干了没有

        同样的缺陷，没干和干了是两种处理。没干透可以稀释后盖过去；干透了只能打磨重来。 判断方法：用一小段纸胶带轻贴再撕，胶带上有漆屑就是没干透。

        橘皮

        断面　漆膜表面是波浪，不是平的。

        长什么样　密密麻麻的小凹坑，反光像橘子皮。

        原因　漆太稠、枪太远、气压不足，或一层喷太厚。

        处理　没干 → 稀释后薄盖；干了 → 800 目湿磨再薄喷。

        预防　稀释到位、距离 15–20 cm、先薄后湿。

        流挂

        断面　某一处漆膜突然变厚，往下坠。

        长什么样　一道漆往下淌，下边缘有厚边。

        原因　一次喷太厚、停枪、距离太近。

        处理　必须干透，打磨掉流挂边缘再薄喷。

        预防　薄喷多层，匀速别停。

        白化

        断面　漆膜内部有细小水汽，整层泛白。

        长什么样　像蒙了一层白霜，光泽和透明最明显。

        原因　湿度太高、稀释剂挥发太快、温度低。

        处理　没干透 → 加缓干剂薄喷；已白 → 打磨重来。

        预防　湿度 <75%，潮湿天用缓干型稀释剂。

        鱼眼 / 缩孔

        断面　漆膜被顶开一个火山口，坑底见到下层。

        长什么样　一个个小圆坑，中心颜色和周围不同。

        原因　表面有油、水或硅（手摸、脱模剂、空压机带水）。

        处理　干透打磨，洗件（加一点洗洁精）再重喷。

        预防　喷前洗件、加水隔、别用手摸。

        干喷

        断面　没有连续漆膜，表面是一层松散颗粒。

        长什么样　粗糙发粉、反光发哑，摸上去像砂纸。

        原因　距离太远、气压太大、漆太稀。

        处理　打磨平，拉近、降气压重喷。

        预防　距离 15–20 cm，气压 1.5–2 bar。

        遮盖渗漆

        断面　两种颜色在胶带边缘互相咬进去。

        长什么样　交界处有锯齿状渗色，边缘不齐。

        原因　胶带没压实、边缘翘起、一次喷太湿。

        处理　干透后补边，局部重新遮盖再喷。

        预防　压边压实，先薄喷一层「封边」。

        颗粒

        断面　漆面里嵌着异物，凸出来。

        长什么样　凸起的小点，反光时很明显。

        原因　空气里的灰尘、漆没过滤、干喷的漆雾落下。

        处理　干透后用 1500 目打磨，再抛光。

        预防　漆过一遍滤网，喷前地上洒水降尘。

        漏喷 / 薄厚不均

        断面　漆膜一头厚一头薄，薄处透底色。

        长什么样　有的地方深、有的浅，侧面看有明显色块。

        原因　重叠率不够、边角没先喷、走枪速度不一致。

        处理　整体薄薄补一层。

        预防　重叠 1/3，先边角后大面。

        三条通用原则

        1. 先停手，别趁湿补救。　湿的时候动它只会越弄越糟，等干了再处理。

        2. 打磨是最后手段。　每磨一次就少一层漆，磨穿底色就得从头来。

        3. 同一个问题连着出两次，先停。　多半是漆或设备的状态变了（稠了、堵了、湿度上来了），不是手的问题。

        模型说明：采用库贝尔卡－蒙克单常数理论；每支漆的吸收/散射曲线由其屏幕色反推，屏幕色本身是近似值，未做实物标定。 色差（ΔE00）小于 2 表示肉眼基本难以分辨。结果用于定方向和比例，正式上色前先在小样上试。
